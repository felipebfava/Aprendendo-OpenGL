### Sobre
Repositório destinado aos estudos sobre OpenGL utilizando a linguagem Python para a disciplina de Computação Gráfica

Para executar você deverá criar um ambiente virtual python, como:
```js
python -m venv .venv
```

Agora para instalar as dependências:
```js
pip install PyOpenGL PyOpenGL_accelerate glfw
```

Depois disso, entre em uma pasta e rode o código python normalmente dentro do ambiente virtual:
```py
python <nome do arquivo .py>
```
